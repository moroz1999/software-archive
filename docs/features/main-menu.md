# Main Menu

The bar over every page: Home (`/`), Software (`/software`, [software-list.md](software-list.md)), Authors (`/authors`, [author-catalog.md](author-catalog.md)). The section of the current page is marked, including the pages inside it (a software's or an author's page); Home only on the home page.

The not found page and the error page keep the menu: the route error boundary sits inside the frame of the menu, and an address the app does not know is a route of its own that throws not found.
