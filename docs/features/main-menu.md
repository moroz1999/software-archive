# Main Menu

The bar over every page: Home (`/`), Software (`/software`, [software-list.md](software-list.md)), Authors (`/authors`, [author-catalog.md](author-catalog.md)), Groups (`/groups`, [group-catalog.md](group-catalog.md)), Categories (`/categories`, [category-catalog.md](category-catalog.md)), and on the right the search button ([quick-search.md](quick-search.md)) and the platform and language switches ([platform-switch.md](platform-switch.md), [localization.md](localization.md)). The section of the current page is marked, including the pages inside it (a software's, an author's or a group's page, a category's editing); Home only on the home page.

The not found page and the error page keep the menu: the route error boundary sits inside the frame of the menu, and an address the app does not know is a route of its own that throws not found.
