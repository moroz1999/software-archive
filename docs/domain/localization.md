# Interface Languages

Visitors can use the archive interface in English or Russian. The first visit follows a supported browser language and otherwise uses English; an explicit choice is remembered for later visits.

Interface text and presentation formats such as dates follow this choice, and so do the names kept in several languages: of categories, countries, cities, platforms and hardware. Russian is the language every such name has; one missing in the chosen language is shown in Russian. Other archive content keeps the language in which it is stored.

More languages will come.
