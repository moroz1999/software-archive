# CardScreenshots

`CardScreenshots` — the pictures of a card in a 4:3 frame, each shown whole. The first is shown; pointing across the frame goes through the others, each owning an equal strip of the width, with a bar per picture along the bottom marking the one shown. Leaving the frame, or getting other pictures, shows the first again. Only the shown picture is named, by `alt`; all are loaded lazily. A single picture has no strips.
