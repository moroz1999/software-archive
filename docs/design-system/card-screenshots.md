# CardScreenshots

`CardScreenshots` — the pictures of a card in a 4:3 frame, each shown whole. The first is shown; pointing across the frame goes through the others, each owning an equal strip of the width, with a bar per picture along the bottom marking the one shown. One picture fades into the next. Leaving the frame, or getting other pictures, shows the first again. Only the shown picture is named, by `alt`. The first is loaded lazily, as it comes near the screen; another is put in the frame, and so loaded, only once it is pointed at, and stays there: pictures hidden in the frame would all load at once, lazy or not. A single picture has no strips.
