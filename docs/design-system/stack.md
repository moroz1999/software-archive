# Stack

`Stack` — children one under another.

- `gap`: `none` | `xs` | `sm` | `md` (default) | `lg` | `xl` | `xxl` — the gap scale shared by all layout components.
- `align`: `center` | `start` | `end` | `stretch` — cross-axis alignment; the flex default when omitted.
- `as`: `div` (default) | `section` | `ul` | `ol` | `li`; as a list it drops the markers and indents.
