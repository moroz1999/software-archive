# Inline

`Inline` — children in a row.

- `gap`: the shared gap scale, `md` by default.
- `align`: `center` | `start` | `end` | `stretch` | `baseline`; `justify`: `start` | `center` | `end` | `between`.
- `wrap` lets children move to the next line when out of room; off by default.
- `as`: `div` (default) | `span` | `ul` | `li`; as a list `ariaLabel` names it.
