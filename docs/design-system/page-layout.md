# PageLayout

`PageLayout` — the frame of a routed page: the page's only level 1 heading over its content blocks, centred within a maximal width. Independent content blocks are its direct children and get the large block gap between them. `title` is usually text; a page whose heading comes with its data passes a skeleton bone while it loads. `actions` — the page's buttons, on the title's line at its end (below it on narrow screens).
