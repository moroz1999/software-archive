# FileUpload

`FileUpload` — choosing files by its button, or dropping them on it; `onFiles` gets the files, never none. `accept` and `multiple` are those of a file input; the input itself is hidden and named by `label`, so the same file can be chosen twice in a row. `disabled` locks the button and ignores drops. Dropping is a pointer's shortcut only: the button stays the way in for the keyboard.
